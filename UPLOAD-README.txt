AeroCRNS — النسخة الكاملة بعد تحديث الحساس

تحتوي هذه النسخة على تصميم المنصة الأصلي، مع الحساس الجديد المستمد من الصور:
حامل ثلاثي، لوحة شمسية، وحدة تحكم وهوائي، جسم معدني برأس مثقّب ومدبّب.
أوضاع العرض: الجهاز كاملًا، المقطع الداخلي، تفكيك الطبقات.
بيانات المحاكاة وحسابات CTS وملفات التنسيق الأصلية محفوظة كما كانت.

طريقة الرفع:
1. فك ضغط الحزمة على جهازك؛ لا ترفع ملف ZIP نفسه كبديل لملفات الموقع.
2. افتح المجلد في مستودع مشروع AeroCRNS الذي يحتوي على index.html الحالي.
3. ارفع محتويات هذه الحزمة إلى ذلك المجلد، بما فيها مجلد vendor كاملًا.
4. حافظ على أسماء الملفات ومواقعها. رفع الملفات إلى المسارات نفسها يحدّثها.
5. احفظ التغييرات عبر Commit changes. لا تحتاج إلى حذف الملفات القديمة أولًا.
6. بعد انتهاء نشر GitHub Pages، افتح رابط GitHub Pages وحدّث الصفحة باستخدام Ctrl+Shift+R.

إذا كان index.html الحالي في جذر المستودع، ارفع المحتويات إلى الجذر.
إذا كان داخل dist، ارفع المحتويات إلى dist وفق إعداد النشر الموجود.
لا تضع الحزمة داخل مجلد إضافي باسم AeroCRNS-final-site داخل مجلد النشر.

هذه حزمة للموقع الثابت؛ لا تحتاج إلى node_modules أو مجلد .openai.
تسليم هذه الملفات لا يحدّث رابط chatgpt.site تلقائيًا.
